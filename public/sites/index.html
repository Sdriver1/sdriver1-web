About Me

Hi! I'm Steven Driver, also known as Sdriver1. I'm a second-year Computer Science student at RIT (Class of 2030). I build Discord bots, web apps, and the infrastructure they run on. My main project is Pridebot, a multi-function LGBTQIA+ Discord bot that serves 19k+ servers and over 1.3M+ users. I work mostly in JavaScript/TypeScript on Node.js, plus Java and Python for coursework and side projects. I self-host nearly everything I build on a two-server homelab using Docker, Cloudflare, and Tailscale. I'm currently a Software Developer Associate at devEco Consulting and a Reviewer for Top.gg. Away from the keyboard, I've been a lifeguard and swim instructor since 2023.
